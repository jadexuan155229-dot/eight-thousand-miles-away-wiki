# 凡例 · 初稿待审清单

文件：`src/fanli.jsx`（中文界面的 `#/about`，导航末一签「凡例」）。**你只看这份清单**，其余照稿上线；要改哪条，告诉我条号或直接改原文。

## 本稿做了什么

- **定位**：凡例说明站上的体例——哪些是史实、括注里那些字是什么意思、各图怎么读。英文版同一路由仍是 About（交代唐代背景与剑三来源），两页各为其读者而写，不互译。
- **体例**：仿古书凡例，条号连贯全篇（一至二十七），分「史实与虚构」「纪年」「括注」「人物档案」「诸图」「余波」「文库」「文字」八节。诸图、余波、文库各条里的页名可点，直达该页。
- **材料**：每条都对过站上实况——括注诸标记按年表、档案里实际出现的写法与次数归纳（推定 23 处、约 33、待核 13、按语 12、《通鉴》14、月份待核 7、作者定 5、俟核 3）；档案诸栏照弹窗实有的标目；编制、余波的图例照图上的说明。年表条数（621）、史实条数（104）由数据实算，增删事件不必回改。
- **用字**：凡例正文用繁体；引数据原文处（括注、编号、年号写法、人名）照原样用简体，放在引号里、淡一阶显示。
- **手机导航**：添一签后窄屏（≤ 390px）折作四行、「纸色」独落末行；中文页签左右留白收至 12px，360–599px 皆回三行，同添签以前。

## 待作者定

1. **用字**。我把凡例算作界面（它和图例说明一样，是教人怎么读这个站），故用繁体，同「界面一律繁体」。另一读法：凡例是作者对读者说的话，同余波页「作者按」，该用简体。改起来是整篇一转。
2. **第二条**「小说与史实相牴触处，依史改正，并于括注说明」——据年表 763.7「据史与文档改——凉州764、甘州766方陷」一类概括。若这只是个别几处、不算通例，改作「间有依史改正者，括注说明」。
3. **第四条**「人物多为作者所造，少数取自游戏本事」——英文 About 点了薛直之名，中文这里没点。要不要点名、点谁？
4. **第七条**「月为农历月」——照英文 About 的说法。请确认。另：不记月者现在排在当年诸事之首（代码如此），若你更愿意排在年末，那是改排序，不止改凡例。
5. **第九至十四条**（括注）——释义是我从用法归纳的，请逐条看。尤其：「推定」「系年约」「月份推定」三者我并作一条；「俟核」与「待核」并作一条；「约」我写作「年份或岁数为约数」。有没有漏掉的标记？
6. **第十五条**（档案诸栏）——照弹窗实有标目全列：名字训诂、八目、高光、轶事、任职履历、关系、同事人物、所系之事、见于文库。要不要删繁，只说八目？
7. **第十六条**「档案与年表细节不一处，以年表为准」——这是你 11-24 定给我的工作规则。要不要公开给读者？
8. **第二十四条**（余波）——「在场姿态」写作「他与此事的位置」，「记忆方式」写作「事后如何带着它过下去」，意思取自英文 About（how each person carries them afterwards）。你在余波草案里说记忆方式是这一层的核心声部，这一句的措辞最该你定。
9. **文库**——没写原稿正文的早晚（比如登楼、郎心是早期文字、将来要重写）。要不要告诉读者？
10. **引言**——「《八千里路》是一部长篇小说。本站是它的工作档案：写作所据的人物、系年、地理与关系，连同原稿正文，尽列于此，供人翻检。」请看措辞。
