## 作者已裁定

1. 震源名「大光明寺·陆羽鸣之死」；仇怨另立一条「大光明寺·恩仇」（待做），程凯城楼一箭、陆隐一案归彼。
2. 程凯自本表删去；陆南信节点写作「被（程凯）射穿右肘」。
3. 陆南信原记忆方式并了两件事，拆开：本表取「认出那半句」，「失了双刀」留给恩仇一条。
4. 高垣不知情。陆危楼进表，知情。
5. 岚川云 756.7B 细节未定，先占位。
6. 岚川云所得为陆羽鸣的**萨珊玛瑙印石**，不是身份牌／腰牌；余波层与年表措辞一律改为印石。
