# 工作文档总目

docs/ 里是写站过程中的工作文档：进度与体例、英译审稿清单、内容草稿与核对。网站不读这里的任何文件。

**状态以站内数据和[更新记录](changelog.md)为准。** 不少草稿顶头的「起草待核」写于起草当日，此后已裁定、上线，文件本身没有回头改；要知道某事现在如何，看站上，或在更新记录里搜。

文件一律不挪：互相引用、代码注释里提到的路径有上百处，挪了就断。新文档照旧放在 docs/ 根下，在这里补一行。
