## 〇 先看这三条

1. **你已经给了每个人的终点**（战后的勋官、散官和职），缺的是中间怎么走上去。三个人我排成三条不同的路：
   - 程凯走**营伍**：新兵 → 旅帅 → 天弓营副尉 → 校尉 → 教练使
   - 李庭深走**府僚**：参军事 → 兵曹参军事 → 留后（代领残营）→ 兵马使
   - 岚川云走**差遣**：斥候 → 斥候首（无品）→ 旅帅、仍充斥候首 →（在苍云当教官）→ 回府掌斥候
2. **战后的位子都是接死者的缺。** 教练使原是杨宁（天宝十五载城下战死），兵马使原是徐长海（出荥阳殉城）。正文里不必点破，但排出来是成立的，也和剑三原设定对得上：剑三里杨宁就是教练使，徐长海就是兵马使。
3. **职、勋、散分三层记。** 职是做什么，勋是军功转数，散是本品。沿用你人设卡「前勋后散」的写法。

我顺手调和了两处：

- **营的人数**：你的笔记取 250 人，757 年又写「三百人营」。建议编制按折冲府「三百人为团」记 300，实额常常不满，约 250。这样两处都对。
- **副将还是副尉**：人设卡写程凯是「天弓营副将」，〈756-1 万花来〉写「营中副尉」。建议职名记副尉，副将是营中俗称，和〈770 年末〉「队正副将」那种泛称一样。

称呼惯例（从你文中归纳，不是我加的）：
- 副尉以上称将军，如「子阳将军」；
- 按散官称校尉，如魏谦是翊麾校尉，人称「魏校尉」；
- 以驻地代称，如「知节殿将军」（作者 2026-11-24 定：称人不单用「知节殿」）。

### 2. 散官、勋官（只列用得上的）

**散官（本品）**：
- 忠武将军，正四品上；壮武将军，正四品下
- 游击将军、归德郎将，从五品下
- 振威校尉，从六品上；翊麾校尉，从七品上

名号带「怀化」「归德」的那一系列专授蕃官。

**勋官**：
- 八转上轻车都尉，比正四品
- 五转骑都尉，比从五品
- 三转飞骑尉，比从六品

你人设卡里的勋和散基本是同品成对的，比如程凯是上轻车都尉加壮武将军，齐晟是骑都尉加游击将军。下面的推定沿用这个习惯。

## 五 要你拍板的

1. **岚川云：**「无品级的斥候首」和「称旅帅」，我用 752 年那次赏接起来。行不行？
