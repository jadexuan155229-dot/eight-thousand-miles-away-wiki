### 修：前进后退后网址与界面语言不一致

- 审查发现：站内换语言用 `replaceState` 只改当前一条历史记录，此前各条仍是旧语言的路径；前进后退在同一文档内换条、不重载，语言状态又只在启动时读一次网址，于是退回 `/#/chars` 而界面仍是英文（反之亦然），此时刷新或转发链接，所见语言与眼前不同。
- 修法：`useLanguage` 监听 `popstate`，每次前进后退都按路径重定语言。换语言本身仍不另记一条历史（不算一次导航），后退即回上一页、按上一页网址的语言显示。
- 新增 `npm run check:history`（`scripts/history-check.js`）：临时开发服务器加本机 Chrome，走三组中英切换后的前进、后退、刷新，逐步比对网址、`<html lang>`、界面三者。改前 5 步不合，改后全合。

### 余波：选中一行后，详情在图下有浮签提示；详情底部可回到图上

作者指出：余波页点选一人，其回响只在图例之下展开，行多时整段落在首屏之外，初来者会完全错过。

- 不替人滚动——逐行对照时每点一下都被拽离图表，反失其图。改为详情未入视野时，于屏底浮一小签「↓ 某某 · 回响展开在图下」（英文版 “— echoes open below”），左缘作其门派色；点之平滑滚至详情并移焦于其上（键盘、读屏可续读），减少动效时直接跳转。

- 图例补一句「点选一行：回响展开在图下 ↓」。
- **键盘与读屏**（review P2：浮签在 DOM 上位于图表与详情之后，Tab 要穿过后续各行与详情控件才到；出现时也无告知）：选中行左栏姓名之下添一枚「回响详情 ↓」入口（英文 “Echoes below”），DOM 上紧随该行，键盘选中后 Tab 一下即到，Enter／空格直达并移焦于详情；目视者亦在所点之行旁见之。为此选中行至少展开一道（无定年节点之行原不展开）。选中时以一句话告知读屏「某某的回响已在图下展开；按 Tab 至『回响详情』可直达」，详情区撤去 `aria-live`（原会整段通读），改加 `aria-label`。浮签只为目视、用鼠标者，退出键盘顺序（`tabIndex -1`、`aria-hidden`）。
- 详情底部右侧添「回到图上」（英文 “Back to the chart”）：回到所选那一行，令其居于屏中并移焦其上，便于接着点下一人对照；回去后详情复在屏外，浮签随之重现。上箭头不在字体子集中，以 ↓ 倒转代之，免为一字重切字体。
- 阴影用 `T.xShadowTip`（浮签阴影），两肤各自取值。
